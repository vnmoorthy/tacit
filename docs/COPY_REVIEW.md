# User-facing copy review

Reviewed the working tree on 2026-09-18, including the untracked `Landing.tsx` and existing uncommitted UI changes. This is a report only; no components were edited. Line references identify the reviewed version and may move as the UI changes.

Scope: every line of all 10 files in `apps/web/src/pages/` and all 8 files in `apps/web/src/components/` (4,015 lines). Checked headings, explanatory text, examples, buttons, placeholders, status messages, empty states, tooltips, accessible labels, and computed strings. Provider-generated answers, transcripts, and errors cannot be fully proofread from these files.

Use **capture** for an expert's collected interviews and knowledge, **session** for one interview, **knowledge atom** for one saved item, **domain** for a topic in the coverage map, and **twin** for the assistant that answers from a capture. Introduce those terms in plain language before shortening them. Keep sentence case, capitalize **Markdown**, and distinguish extraction confidence from coverage. “Profile” is not used as a competing name in these files.

The tables contain 38 proposed changes. Quoted current text is a literal excerpt or a rendered example of an interpolated string; braces stand for dynamic values. Prioritize statements that misdescribe behavior before stylistic improvements. A label proposal does not by itself fix an interaction or accessibility issue; those belong in the accessibility report.
